# Contributing

Thank you for helping improve Comparative Analysis of Radar Signal Classification.

## Current priorities

The repository currently documents the project without a runnable implementation. Useful contributions include correcting documentation, adding reproducibility details, and providing source code or examples that the maintainer is entitled to publish.

## Report an issue

Open an issue at https://github.com/Yhdbbdb/COMPARATIVE-ANALYSIS-OF-SIGNAL/issues. Explain the problem, reference the affected section or file, and describe the expected behavior. For numerical or scientific claims, include the method, assumptions, and supporting evidence.

## Submit a pull request

1. Fork the repository and create a focused branch.
2. Make a small, clearly described change.
3. Check Markdown links and formatting. For code or model changes, describe how you ran them, including software versions, inputs, and observed results.
4. Open a pull request explaining the change and its validation. State any checks you could not run.

There is no automated test suite or runnable baseline currently published. Do not claim tests passed without performing them. Avoid adding unsupported performance claims.

## Data and attribution

Only contribute material you have permission to share. Cite external sources and preserve copyright notices. Do not upload secrets, private sensor data, restricted datasets, or third-party documents without permission. For datasets, document provenance, units, labels, and redistribution terms.

## Licensing

The maintainer has not yet adopted the proposed license in this documentation package. Resolve licensing with the maintainer before contributing substantial code or redistributing existing material. Keep discussion constructive and respectful.
